# Changes Log - 2026-08-14

This note records all work done today in simple language.

## Quick Overview

- Rebuilt the mobile app's Catalog filter bar to match the redesign already shipped on desktop web yesterday — replaced the two rows of scrolling pill chips with a compact "Brand | Status | Type" button row that opens bottom-sheet pickers.
- Brand filter is now multi-select (was single-select before), with a searchable checkbox list, alphabetical sorting, and already-picked brands pinned to the top of the list.
- Added a new "Type" filter (Chase, Event Car, Black Edition, Limited Edition) — wired to a database field that was already being captured when logging a purchase, but never surfaced anywhere in the catalog before.
- Removed the "Not owned" status option — not useful without a wishlist feature, which doesn't exist yet.
- Fixed the new filter sheet getting hidden behind the on-screen keyboard while typing in the brand search box.
- Files touched: `mobile/lib/data/models/catalog_item.dart`, `mobile/lib/data/models/purchase.dart`, `mobile/lib/features/catalog/catalog_data.dart`, `mobile/lib/features/catalog/catalog_screen.dart`, `mobile/lib/features/catalog/widgets/filter_sheet.dart` (new), `mobile/test/insights_data_test.dart`, `mobile/test/scan_matching_test.dart`.

## What Changed

### 1) Catalog filter bar redesigned (mobile)

- Old: two rows of horizontal pill chips — one for brand, one for owned/pre-order status.
- New: a single row of three buttons — **Brand**, **Status**, **Type** — each opens a bottom sheet with Clear/Apply actions, styled after a reference app (DIE CARZ) the user shared for inspiration.
- The Type button only shows up when there's actually something to filter by — it hides itself if nothing in the current catalog is tagged Chase or any special edition.
- An overall "Clear all filters" icon appears once any of the three categories is active.

### 2) Brand filter is now multi-select, searchable, sorted, and pins your picks to the top

- Previously the brand row let you pick only one brand at a time.
- Now you can tick as many brands as you want. Once there are more than 6 brands, a search box appears above the list (same idea as the reference app's Series filter). The list is alphabetically sorted (case-insensitive) so it no longer appears in a random/jumbled order.
- Once you've ticked some brands, they float to the top of the list above a divider — so you don't have to hunt through the whole list to see what's already selected, matching the behaviour in the reference app.

### 3) New "Type" filter — Chase / Event Car / Black Edition / Limited Edition

- The purchase-entry forms (web) have captured an "edition type" per purchase for a while (`normal`, `event_car`, `black_edition`, `limited_edition`), but the catalog never read or filtered by it — mobile or web.
- It's now pulled into the mobile catalog data per item, and a new multi-select "Type" filter lets you narrow the catalog down to Chase and/or any of the three special editions, in any combination.

### 4) "Not owned" status removed

- The Status filter is now just All / Owned / Pre-order. "Not owned" didn't mean anything useful without a wishlist feature to back it, so it was dropped rather than kept as dead weight.

### 5) Filter sheet no longer hides under the keyboard

- Typing in the new brand search box pushed the sheet content down under the on-screen keyboard, hiding the search box and the Apply/Clear buttons.
- Fixed by padding the sheet for the keyboard's height as it opens, and wrapping the sheet's content in a scroll view as a safety net so it can't overflow off-screen on shorter phones either.

## User Impact

- Mobile catalog filtering now matches the redesigned desktop web experience, and is much faster to use once there are a lot of brands.
- Can filter to see just Chase, Event Car, Black Edition, or Limited Edition items for the first time — this wasn't possible anywhere in the app before.
- Typing to search brands no longer breaks the filter sheet's layout.
