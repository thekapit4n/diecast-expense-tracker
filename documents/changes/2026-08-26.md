# Changes Log - 2026-08-26

This note records all work done today in simple language.

## Quick Overview

- Catalog brand filter: once a brand is ticked, it now jumps to the top of the list instead of staying wherever it falls alphabetically.
- Purchase List and Collection List: the "Brand" column filter is now a tick-list of brand names, instead of a text search box.
- Purchase List: the "Payment Status" column filter is now a tick-list too (Paid / Unpaid / Refunded), instead of a text search box.
- Files touched: `app/catalog/components/BrandPicker.tsx`, `components/purchase/purchase-grid.tsx`, `components/collection/collection-grid.tsx`.

## What Changed

### 1) Catalog brand filter — selected brand jumps to the top

- On the Catalog page, the brand filter (desktop dropdown and the mobile "Filter & Sort" sheet) lists brands alphabetically. If a brand like "MINI GT" was already selected, it stayed buried in its A–Z position, so picking it back out of a long list meant scrolling to find it again.
- Now, whichever brand(s) are ticked move to the top of the list, in front of everything else. Untick everything and the list goes back to plain A–Z order.

### 2) Purchase List & Collection List — Brand filter switched to checkboxes

- Both grids' "Brand" column filter used to be a text box (contains / equals / starts with). To filter by "MINI GT" you had to type it out, and it only matched what you typed — no way to see all the brand names that actually exist in the list.
- Switched to the grid's built-in tick-list filter (the same style already used on the "Edition Type" column) — clicking the filter icon now shows every brand name that appears in the data, each with a checkbox, so you can tick one or several at once.

### 3) Purchase List — Payment Status filter switched to checkboxes

- Same change as above, applied to the "Payment Status" column — instead of typing "unpaid" into a text box, the filter now shows a tick-list of the payment statuses in use (Paid, Unpaid, Refunded, etc.) to check off.

## User Impact

- Finding and re-picking an already-selected brand in the Catalog filter no longer means scrolling through the whole alphabet.
- Filtering the Purchase List and Collection List by brand, or the Purchase List by payment status, is now point-and-click instead of typing exact text matches — and you can see every option and select more than one at a time.

## Notes for Next Time
