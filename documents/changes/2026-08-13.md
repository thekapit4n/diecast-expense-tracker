# Changes Log - 2026-08-13

This note records all work done today in simple language.

## Quick Overview

- Redesigned the Catalog page's filter controls for desktop/laptop screens — the old brand pill row couldn't be scrolled with a mouse, so most brands were unreachable.
- Added a "Chase only" filter, which didn't exist before.
- Fixed chase and normal-version catalog cards (same item number) showing the wrong photo — both were displaying the chase version's picture.
- Files touched: `app/catalog/components/CatalogClient.tsx`, `app/catalog/components/FilterSortSheet.tsx`, `app/catalog/components/BrandPicker.tsx` (new), `app/catalog/components/DesktopFilterBar.tsx` (new), `lib/collection-images.ts`, `app/api/management/collection-image-upload/route.ts`.

## What Changed

### 1) Catalog page filters redesigned for desktop/PC

- The row of brand buttons under the Catalog header (All, Almost Real Model, CMModel, ...) scrolled sideways, but on a desktop browser there's no visible scrollbar and no easy way to drag it with a mouse — so anyone browsing on a PC or laptop could only ever see the first few brands.
- On screens 1024px wide and up, that row is now replaced with a row of filter buttons: **Brand** (click to search and tick brands from a list), **Type** (owned / pre-order / not owned, plus a new "Chase only" toggle), **Scale**, and **Sort**. A "Clear filters" link appears once anything is picked.
- Phones and narrow browser windows are untouched — they still get the original scrollable brand pills plus the "Filter & Sort" bottom sheet.
- The brand picker (search box + tickable list) used in the new desktop bar is the same one now used inside the mobile "Filter & Sort" sheet too — previously that sheet showed every brand as a big grid of buttons; now it's a single "Brand" button that opens the same searchable list, so it doesn't take up the whole sheet.
- Along the way, a bug was caught and fixed where the new filter buttons looked clickable but did nothing — the button component wasn't correctly wired to the popup menu underneath it.

### 2) "Chase only" filter added

- There was no way to filter the catalog down to just chase variants before. It's now a toggle inside the "Type" filter (desktop) and next to Owned/Pre-order/Not owned (mobile sheet).

### 3) Chase and normal catalog cards showing the same photo

- Reported: two cards with the same name and item number — one marked "Chase", one the regular version — both showed the chase version's photo.
- Cause: the chase and normal versions of an item are two separate catalog cards, but they both read from one shared notes field (`remark`) on the underlying collection record. When a chase photo was uploaded, its web address got written into that shared field, and the normal card's photo-lookup logic didn't know to skip web addresses that belonged to the chase folder — so it picked up the chase photo too.
- Fixed by (a) making the normal card's photo lookup skip any address containing a chase folder path, and (b) no longer writing chase photo addresses into that shared field when uploading, so this can't happen again going forward.
- Because photos are looked up live from that field rather than stored as a fixed list, this fix applies immediately to already-affected items too — no data cleanup needed, just refresh the page.

## User Impact

- Anyone browsing the catalog on a desktop or laptop can now actually reach and filter by every brand, not just the first handful.
- Filtering by chase items is now possible.
- Chase and normal versions of the same model now correctly show their own separate photos.
