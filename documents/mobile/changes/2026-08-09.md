# 2026-08-09 — Bottom nav and Home dashboard icons switched to HugeIcons

## Quick Overview

Replaced the Material icons in the bottom navigation bar and on the Home
dashboard's stat cards with icons from **HugeIcons** (stroke-rounded style),
so the app has one consistent icon look instead of mixing in the default
Flutter/Material icon set.

Files touched:

- `mobile/lib/features/shell/main_shell.dart`
- `mobile/lib/features/home/home_screen.dart`
- `mobile/lib/core/icons/huge_scan_search_icon.dart` (new)
- `mobile/pubspec.yaml`, `mobile/pubspec.lock` (added the `hugeicons` package)

## What Changed

### 1. Bottom navigation bar icons

All five tabs now use HugeIcons instead of Material icons:

- **Home** → Home-01
- **Catalog** → Grid View
- **Scan** → Scan-Search
- **Pre-orders** → Package Process
- **Insights** → Chart Analysis

Most of these come straight from the official `hugeicons` Flutter package,
which ships a free set of about 5,100 stroke-rounded icons. The Scan tab's
icon (Scan-Search) is not in that free set, even though it is marked free on
the HugeIcons website — so it was rebuilt by hand as a small custom-drawn
widget, using the real path data from the icon's downloaded SVG file. It
looks identical to the original; it just is not pulled from the package.

### 2. Home dashboard stat card icons

The five summary cards at the top of the Home tab were also switched over:

- **Models owned** → Car Parking
- **Units owned** → Garage
- **Active pre-orders** → Package Process (now matches the Pre-orders tab
  icon, so the same status reads as the same icon everywhere in the app)
- **Ready to collect** → Package Delivered
- **Unpaid / partially paid orders** → Transaction

### 3. Added the `hugeicons` package, and a Pods hiccup along the way

`hugeicons: ^1.1.7` was added to `pubspec.yaml`. After running `flutter
clean` and `flutter pub get` for the new dependency, Xcode's build briefly
failed with "Unable to load contents of file list" errors for the Release
configuration — the CocoaPods project files had gone stale and needed
regenerating. Running `pod install` again (with `LANG=en_US.UTF-8`, since
CocoaPods on this Mac needs that set explicitly or it crashes) fixed it, and
the build went through afterwards.

## User Impact

- The bottom nav and the Home dashboard now share one icon style, instead of
  mixing in the generic Material icon look.
- The "Active pre-orders" stat on Home now uses the exact same icon as the
  Pre-orders tab, making the connection between the two clearer at a glance.
- No behaviour changed — this is a visual-only update.
